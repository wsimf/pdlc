What I learned building with agents

Fast is easy.
Confidence is harder.

We set the direction. We define how we’ll know it’s right.

Agents carry that direction through planning, implementation, testing, and review, bringing decisions back to you and recording progress and evidence in your Azure (or GitHub) board.

The friction

The code comes fast.
The follow-through takes work.

These are the gaps I’m trying to close.

  • “We already agreed on this.”

    Context gets lost between sessions and agents. I end up repeating requirements, constraints, and decisions.

  • “That’s not what we needed.”

    An agent starts coding before the problem is clear, fills in the gaps, and delivers against its own assumptions.

  • “Done — but does it work?”

    Passing tests can miss the requirement. Integration, edge cases, and the real user journey still need verification.

  • “Why am I still chasing this?”

    I’m prompting the next step, checking what was actually done, and carrying progress from the chat back to the board.
